# 개인 웹사이트

비 오는 네온 도시 픽셀아트 배   경(순수 CSS)을 사용한 개인 웹사이트입니다.

- `index.html` — 페이지 내용 (이름·소개·프로젝트 등은 여기서 수정)
- `style.css` — 레이아웃과 색상
- `scene.css` — 배경 애니메이션 (`src/scene.scss`를 컴파일한 결과)
- `src/scene.scss` — 배경 애니메이션 원본. 수정 후 `npx sass --no-source-map --style=compressed src/scene.scss scene.css`로 다시 컴파일

배경 애니메이션은 CodePen의 cassidoo 작품을 참고했습니다.
